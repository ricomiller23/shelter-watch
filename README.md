# SHELTER.WATCH
Global Housing, Rents & Cost-of-Living Monitor (Volume II, Part 16)

## Core Invariant Principles
1. **An Index Is Not a Price**: The Case-Shiller index (336.663) is repeat-sales normalized to Jan 2000 = 100 and must never be treated as dollar currency.
2. **Three-Month Moving Average with Two-Month Lag**: Every observation renders `Period {month} · released {date}`.
3. **SA vs NSA Segregation**: Seasonally adjusted and unadjusted series never blend unflagged.
4. **Metro-First Architecture**: National averages are a header; metro telemetry is primary.
